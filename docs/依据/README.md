## 三条不能破的硬规矩

1. **"科学依据/可量化/国标"这类话只许用于 A 档与 B 档**（A＝现行国家/国际标准里能对上的量化口径；B＝同行评议论文与可复算公式）。C 档（行业体系、教材口诀）与 D 档（八字五行）分开摆，混一句进对外文案就是虚假宣传。
2. **缺测不出分**。规则判据要的字段没填，就走"没量"分支；不许用默认值算出一个看起来像实测的数。这条曾在肩宽那 3 条上被违反 ⇒ **10-08 已撤干净**：`computeShoulderRatio` 缺肩宽或缺身高返回 `{}`（不再编 23.5/normal），`computeBodyShape` 胸/腰/臀缺任一项返回 `{}`、上身占优但没量肩宽只标 `body_shape_status:'unmeasured'`（不再拿 `shoulder||38` 判成苹果型）。现场见 `docs/上衣量化依据与公式清单.md` 第 4 节第 4 条。
3. **档位标签与出处必须一起出现**。前端 `EvidenceTag.tsx` 展示 A/B/C/D 时，说明文案里点的每个标准号都得能在本目录里查到原文级证据。

## 一句话总账

97 条种子规则里，只有 9 条（肩宽 3 / 腿身比 3 / 腰臀比 3）够得上"现行标准或同行评议"级的量化；色彩族 44 条是 A 档公式 + C 档手拍权重；场合 6 条、Kibbe 10 条、四季/十二型 44 条属行业体系；五行 25 条属另一套体系。**没有任何现行国标、行标或同行评议文献规定"某人穿某件上衣好不好看"**——可搬的只有尺寸分布、色差公式、和谐指数、几类身体比例的吸引度效应这几类量化物。

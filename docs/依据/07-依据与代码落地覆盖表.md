## 2 现量到的规则覆盖缺口（本表最重要的一行）

库里 `rule_groups` 实测：

- 总 **361** 行，`enabled=1` 也是 361。
- 有 `source_key`（能挂上档位）的 **97** 行，其 `mode` 全是 `all` ⇒ **正好等于三份种子的 97 条**。分布 A 3 / B 6 / C 63 / D 25。
- 没有 `source_key` 的 **264** 行（`mode`＝personal 162 + store 102），`evidence_level` 也全空。按类目：穿搭 139、妆容 45、发型 34、配饰 30、姿势 16。
- 这 264 条不是死数据：样本里"女-通勤-妆容"命中 18 次、"女-通勤-穿搭-暖皮"命中 11 次 ⇒ **它们在生产里真出建议，但对顾客只能显示"未标注，按行业体系（C）对待"**。
- 规则说明页显示"共 199 条"，与库里 361 不等；199 = 97（种子）+ 102（store）⇒ 推断该页按 mode 过滤掉了 personal 那 162 条。这条**未证**，要改页面口径前得先看路由。

⇒ 也就是说：**"依据都写进去了"这句话，对种子那 97 条成立，对库里另外 264 条不成立。**

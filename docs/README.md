## 六、维护约定（改 `docs/` 之前）

1. **只往末尾追加，不改写带日期的历史读数。** 快照表、台账行、"某日现量 N 行"这类句子原地留着，新的读数另起一行带日期。
2. **插了行就重算锚点。** 被按行号引用的对象（代码或 md 正文）一变，跑全仓重扫：
   `grep -rIno "docs/依据/README\.md:[0-9]*" --exclude-dir=node_modules --exclude-dir=.git --exclude-dir=dist .`
   分母要区分"现行定位符"与"带日期的旧读数"，后者⛔ 不换号。
3. **字节数与行数等正文全改完再重量一遍**，不然插一段就把旁边那格的数写废了。
4. ⛔ 新文档不要再按行号引用别的文档——按**名字＋章节号**引用（本文件就是这么写的），行号引用是维护成本最高的一种。
5. 台账一轮＝一行，条目之间留空行；本文件的行数是自指数，落笔即可能过期，用
   `wc -l docs/README.md` 自己重算。
